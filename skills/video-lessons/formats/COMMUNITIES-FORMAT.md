# COMMUNITIES.md Format

`COMMUNITIES.md` lives at the topic root. It lists 2–3 places where the user can test what they learned against real practitioners: ask a question, share a small piece of work, get corrected. Written once when the topic is created, revised when a place turns out to be weak.

## Template

```md
# {Topic} Communities

- [r/{subreddit}](https://reddit.com/r/{subreddit}) (~{size} members)
  {Why it's high-signal: moderation, who answers}. Use for: {kinds of questions}.
- [{Forum or Discord name}]({url})
  {Why it's trustworthy}. Use for: {kinds of questions}.
```

## Rules

- **High-reputation only.** Strong moderation, real practitioners answering, active in the last month. Check before listing. A creator's own Discord counts if it is active.
- **2–3 entries.** More is noise.
- **No pressure.** Lessons may mention a community when a question needs judgment ("people in r/x argue about this; worth asking there"). Never tell the user to post.
- **Respect opt-outs.** If the user says they don't want communities, replace the list with `Opted out on {date}.` and stop mentioning them.
